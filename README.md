# Muchen Cai — Portfolio

A clean, modern one-page portfolio site for Muchen Cai, an AI student at UC Santa Barbara.

**Live site:** https://andyc725.github.io/portfolio/

## Tech Stack

- Pure HTML, CSS, and JavaScript — no frameworks
- Responsive design (mobile, tablet, desktop)
- Dark theme with accent colors
- Smooth scroll animations
- Hosted on GitHub Pages

## Sections

- **Hero** — Name, tagline, and a code-style about card
- **About** — Bio and skills
- **Projects** — Featured work with GitHub links
- **Contact** — Social links and email

## Local Development

Just open `index.html` in your browser. No build step needed.
